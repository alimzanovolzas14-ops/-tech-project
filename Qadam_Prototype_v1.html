A two-minute walkthrough

  1. In Student, choose Use sample profile and open a match explanation.
  2. Apply to Data Analyst Intern, then open Applications.
  3. Switch to Employer, inspect the submitted project note and make an offer.
  4. Return to Student → Applications and accept the offer.
  5. Switch to University and confirm the placement.

Skill coverage = matched required skills ÷ all required skills. It uses self-reported skills, not an AI model or verified qualifications. It is not a hiring probability.
