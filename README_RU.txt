QADAM 2.0 — РАБОЧИЙ ЛОКАЛЬНЫЙ MVP

ЗАПУСК
1. Если используешь ZIP, полностью распакуй его.
2. Дважды нажми START_QADAM.cmd в этой папке.
3. Откроется http://127.0.0.1:8766. Первый запуск занимает около 10 секунд.
4. Нажми Choose a demo account и выбери пользователя.
Для завершения работы запусти STOP_QADAM.cmd. Закрытие вкладки не останавливает приложение.
Повторный запуск сохраняет существующие аккаунты, вакансии и заявки.
На этом компьютере Python уже найден. На другом компьютере нужен Python 3.10+; дополнительные библиотеки не нужны.

ЧТО УЖЕ ЕСТЬ
12 студентов, 4 работодателя, 2 университетских координатора.
8 вакансий, 12 заявок на разных стадиях. Это вымышленные примеры для защиты, а не реальные пользователи и найм.
Все 18 демонстрационных аккаунтов: пароль Qadam2026!
Полный список логинов — ACCOUNTS.txt.

РАБОЧИЕ ФУНКЦИИ
Студент: регистрация, вход, профиль, навыки и проект, поиск/фильтры, объяснение совпадения, избранное, заявки, принятие/отклонение предложения и отзыв заявки.
Работодатель: создание, редактирование, закрытие/открытие вакансий; просмотр своих кандидатов, shortlist, предложение или отказ.
Координатор: студенты и заявки своего университета, подтверждение принятой стажировки с примечанием, выгрузка CSV.
Для всех: собственный кабинет, история заявок и уведомления. Данные сохраняются в SQLite на компьютере.
Доступ проверяется сервером: одного переключения названия роли в браузере недостаточно.

ДЕМОНСТРАЦИЯ НА 3–4 МИНУТЫ
1. Choose a demo account → Aruzhan Saparova (aruzhan@qadam.demo).
2. Discover internships → найди Data Analyst Intern. Python и SQL совпадают, Excel отсутствует: 67% покрытия.
3. View details → Why this match? → Apply to this internship → Submit application.
4. Switch account → Employers → Aida Karim / Steppe Data (steppe@qadam.demo).
5. Candidates → заявка Aruzhan на Data Analyst Intern → View application. Покажи проект и историю, затем Make offer.
6. Switch account → Aruzhan → My applications → Accept offer.
7. Switch account → Universities → Asem Career / AITU (aitu@qadam.demo).
8. Placements → Aruzhan / Data Analyst → Confirm placement. Впиши демонстрационную дату начала и примечание.
9. Статус Confirmed. Export CSV выгружает только записи AITU.
10. Перезагрузи страницу или останови/запусти приложение: данные останутся.
Встроенная кнопка Demo guide напоминает этот сценарий.

Повторная заявка на ту же вакансию блокируется. Чтобы повторить сценарий после завершения, создай нового студента, заполни навыки и проект, затем подай заявку. Работодатель увидит её у себя. Можно также опубликовать новую вакансию.

СОХРАНЕНИЕ И РЕЗЕРВНАЯ КОПИЯ
Рабочая база: full-app/data/qadam.sqlite3. Она создаётся автоматически при первом запуске.
Для копии останови приложение и скопируй этот файл. Архив поставки не содержит сессий и изменений технической проверки.
Для чистой демонстрации можно распаковать комплект в новую папку и запускать её после остановки предыдущей версии.

ЧТО СКАЗАТЬ НА ЗАЩИТЕ
"Our MVP tests whether transparent skill explanations help internship decisions. Students, employers and university coordinators use separate accounts. The local database preserves applications and their history. We distinguish an offer, an accepted offer and a confirmed placement. Our current score is a rule-based baseline; a trained AI model is future work. All preloaded profiles and vacancies are fictional."

ГРАНИЦЫ ВЕРСИИ
Работает локально на этом компьютере, без интернет-хостинга и отправки писем.
Регистрируются новые студенты. Работодатели и координаторы уже созданы для демонстрации.
